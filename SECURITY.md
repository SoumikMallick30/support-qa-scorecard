# Security Policy

## Supported Versions

Security fixes are applied to the latest released version.

## Reporting a Vulnerability

Please do not publish sensitive vulnerability details in a public issue. Use GitHub's private vulnerability reporting feature on the Security tab when it is available. Otherwise, open a public issue that contains only a request for a private contact channel and no exploit details.

Include the affected component, reproduction conditions, potential impact, and any suggested mitigation. Reports will be acknowledged as soon as practical, and confirmed issues will be tracked through a fix and release.

## Data Handling

The hosted calculator runs locally in the browser and does not submit evaluation data to a project server. Contributors must use fictional or anonymized customer information in tests, examples, issues, and pull requests.
