# Sample QA Evaluation

This example demonstrates how the Support QA Scorecard can be used to evaluate a customer support interaction.

> **Note:** This is a fictional interaction created for demonstration purposes.

## Interaction Details

| Field | Details |
| --- | --- |
| Agent | Alex |
| QA Analyst | Demo Evaluator |
| Channel | Chat |
| Interaction ID | DEMO-001 |
| Customer Issue | Customer was charged twice for the same order |
| Evaluation Date | Example |

---

## Sample Interaction

**Customer:**  
Hi, I think I was charged twice for my order. I can see two payments on my bank account.

**Agent:**  
Hello! I'm sorry about the confusion. I'll help you check the duplicate charge.

Could you please confirm the order number?

**Customer:**  
Yes, it's ORD-45821.

**Agent:**  
Thank you. I checked the order and can confirm that only one payment was successfully captured. The second transaction appears to be a temporary authorization hold from your bank.

These authorization holds usually disappear automatically after the bank releases them.

**Customer:**  
How long will that take?

**Agent:**  
It usually disappears within 3–5 business days, depending on your bank. If the second charge is still showing after that period, please contact us again and we'll investigate further.

Is there anything else I can help you with today?

**Customer:**  
No, that's all. Thanks.

**Agent:**  
You're welcome! Have a great day.

# QA Feedback

## What Went Well

- The agent quickly understood the customer's concern.
- Communication was clear and professional.
- The agent provided a useful explanation and expected timeframe.
- Unnecessary customer effort was avoided.
- The interaction had a clear and professional closing.

## Improvement Opportunities

- Provide slightly more personalized empathy.
- Explain what information the customer should have ready if the issue requires follow-up.

## Coaching Recommendation

No formal coaching is required. The feedback can be shared as a minor improvement opportunity.
