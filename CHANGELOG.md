# Changelog

All notable changes to Support QA Scorecard are documented here.

The project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-09-21

### Added

- Browser-based QA evaluation with agent, interaction, analyst, feedback, and coaching fields.
- JSON and CSV report downloads.
- Print-ready evaluation reports.
- Interactive and scripted Python calculator modes.
- Automated Python and JavaScript test suites in GitHub Actions.
- Contributor, security, issue, and pull-request guidance.

### Changed

- Shared web scoring logic now has explicit validation and automated boundary tests.
- The root GitHub Pages application is the single canonical web entry point.
